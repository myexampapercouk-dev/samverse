How to Increase the WordPress Upload Size Limit (and Fix Upload Errors)

Fix "exceeds the maximum upload size for this site": where the limit comes from, how to raise it in hosting settings, why some tricks fail and better options.

Key takeaways
  • WordPress takes its upload limit from PHP settings like upload_max_filesize and post_max_size, which your host controls.
  • Raising the limit in your hosting panel's PHP settings is more reliable than .htaccess, php.ini or wp-config.php tricks.
  • For big files, compressing images and hosting videos on YouTube or Vimeo is often better than a bigger limit.

You try to upload a brochure PDF, a theme zip or a product video and WordPress refuses with "exceeds the maximum upload size for this site". Many guides suggest pasting code into one file or another, and some of those tricks quietly do nothing. Here's where the limit actually comes from, how to raise it properly, and when a bigger limit isn't the right answer at all.

Where the upload limit comes from

WordPress doesn't set its own upload limit. It reads the limits from PHP, the language your site runs on, and those are controlled by your hosting. Two settings matter most:

SettingWhat it controls
upload_max_filesizeThe largest single file PHP will accept
post_max_sizeThe largest total amount of data in one request; it should be equal to or larger than upload_max_filesize
memory_limitMemory available to process the upload, such as resizing a large photo
max_execution_time and max_input_timeHow long PHP waits, which matters for big files on slow connections

WordPress uses the smaller of the first two as your effective limit. On a WordPress multisite network, the network admin settings can set a lower limit on top of this.

Check your current limit

  • Media → Add New: WordPress shows "Maximum upload file size" below the upload area
  • Tools → Site Health → Info: the Media Handling and Server sections list the PHP upload and post size values

Note the numbers before you change anything, so you can confirm afterwards that your change worked.

Raise the limit in your hosting control panel

This is the most reliable method because it changes PHP's settings at the source.

  • Hostinger's hPanel: look in the advanced section for PHP configuration, where a PHP options tab lets you change values such as upload_max_filesize and post_max_size
  • cPanel hosts: look for "MultiPHP INI Editor" or "Select PHP Version", which often has an options tab
  • Other hosts and managed WordPress plans: look for PHP settings, or ask support to raise the limit for you

Increase upload_max_filesize to what you genuinely need, set post_max_size a little higher, save, then recheck Media → Add New. Menu names change over time, so check your host's help pages if you can't find the option. Some budget plans cap these values, and the only way past the cap is a different plan.

.htaccess, php.ini and wp-config.php: why they often don't work

You'll find three popular do-it-yourself methods online. Each works only on certain server set-ups:

  • .htaccess: lines starting with php_value work only where the server supports them. On many hosts they're ignored, and on some they cause a 500 Internal Server Error that takes the whole site down
  • php.ini or .user.ini: a file in the site's main folder can override PHP settings on some hosts, and changes can take a few minutes to apply. Other hosts ignore these files entirely
  • wp-config.php: adding an ini_set() line for the upload size generally has no effect, because PHP doesn't allow upload_max_filesize and post_max_size to be changed once WordPress is already running. The memory setting you may have seen, WP_MEMORY_LIMIT, controls memory, not upload size

If you do try one of these, take a backup of the file first and remove your change if it doesn't help. A forgotten line in .htaccess can cause confusing problems months later. Prefer the control panel whenever it's available.

Other upload errors and what they mean

What you seeLikely cause
"The link you followed has expired" when uploading a theme or pluginThe zip is larger than post_max_size or upload_max_filesize
"413 Request Entity Too Large"A limit on the web server itself, separate from PHP, which your host needs to raise
"The server cannot process the image"Not enough memory to resize a very large photo; see memory limit errors
"Sorry, you are not allowed to upload this file type"WordPress blocks some file types for security; it's not a size problem
"Unable to create directory" for the uploads folderFolder permissions or a full disk on your hosting account
A vague "HTTP error"Often a time-out, memory limit or security rule; try a smaller file and check the error log

For other error messages, see common WordPress errors explained.

Better options for big files

A higher limit fixes the error, but it isn't always the right fix. Large files slow your site and fill your hosting storage and backups.

  • Photos: resize and compress before uploading. A phone photo several megabytes in size can usually be reduced to a small fraction of that with no visible difference on screen; see image optimisation for WordPress
  • Videos: upload to YouTube or Vimeo and embed them, rather than hosting video files on your server; see video on your business website
  • PDF brochures and catalogues: compress them before uploading, especially if they were exported at print quality
  • Very large downloads: consider a cloud storage link for files only a few people need
  • Themes and plugins: upload the unzipped folder to wp-content/themes or wp-content/plugins through FTP instead
  • Migration backups: importing a whole-site backup through the browser often hits these limits; uploading via FTP or using your host's migration tool is usually simpler
