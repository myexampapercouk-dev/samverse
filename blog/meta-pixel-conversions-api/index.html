Meta Pixel and Conversions API Setup for WordPress and Shopify: A Practical Guide for Indian Businesses

How to set up the Meta Pixel and Conversions API on WordPress, WooCommerce or Shopify in India: events, deduplication, consent, testing and common errors.

Key takeaways
  • The Meta Pixel tracks actions in the browser, while the Conversions API sends the same events from your server, so using both gives Meta a more complete picture.
  • Shopify and WooCommerce both have official or well-supported integrations; the key is to send each event once with a matching event ID for deduplication.
  • Test every event in Events Manager, track only the actions that matter to your business, and be clear with visitors about the tracking you use.

The Meta Pixel and Conversions API work together: the pixel records actions such as page views, add-to-cart and purchases in the visitor's browser, and the Conversions API (CAPI) sends the same events from your website's server to Meta. Setting up both on WordPress, WooCommerce or Shopify helps Meta see conversions that the browser alone may miss, which improves ad reporting and optimisation. The important part is sending each event once, with deduplication, and testing it properly.

This guide explains the setup in plain terms for Indian businesses running Facebook and Instagram ads, with notes on Shopify, WooCommerce and lead-generation sites.

Meta Pixel vs Conversions API: what is the difference?

Meta PixelConversions API
Where it runsIn the visitor's browser, as JavaScriptOn your server or platform, sending data to Meta directly
What can block itAd blockers, browser privacy settings, slow-loading scriptsFar less affected by browser blocking
Typical eventsPageView, ViewContent, AddToCart, Lead, PurchaseThe same events, sent from the server
SetupPaste code, or use a plugin or platform integrationPlatform integration, plugin, or a server-side setup
Risk if misconfiguredMissing eventsDuplicate events if deduplication is not set up

Meta recommends using both together. The pixel captures browser behaviour, and CAPI fills gaps when the browser does not send an event.

Which events to track

Track the actions that matter to your business, not everything possible. Common choices are:

  • Online stores: ViewContent, AddToCart, InitiateCheckout, AddPaymentInfo and Purchase with value and currency (INR).
  • Lead generation sites: Lead when a form is submitted successfully, and Contact for WhatsApp or call clicks if useful.
  • Bookings: Schedule or a custom event when an appointment is confirmed.
  • Courses and memberships: CompleteRegistration and Purchase or Subscribe.

Fire the Lead event on a real success, such as a thank-you page, rather than on the button click, so failed submissions are not counted. The guide on thank-you pages for forms explains why this matters.

Meta Pixel and Conversions API setup on Shopify

Shopify has an official Facebook and Instagram sales channel that connects your store to Meta. When you connect it, you can choose a data-sharing level, and the higher setting sends events through both the pixel and the Conversions API without custom code. Standard e-commerce events such as product views, add-to-cart, checkout and purchase are handled by the integration.

A few things to check on Shopify:

  • Remove any old pixel code pasted into the theme, or you may count events twice.
  • Check that COD orders are reported the way you expect, since the order is placed before payment is collected.
  • Review the customer privacy settings in Shopify, which affect what is shared.
  • Confirm the currency is INR and purchase values match your orders.

The Shopify store setup guide for India covers the rest of the store basics.

Setup on WordPress and WooCommerce

On WooCommerce, Meta's official plugin and several well-known tracking plugins can send pixel and Conversions API events. The usual steps are:

  1. Create or select your dataset (pixel) in Meta Events Manager.
  2. Install the integration plugin and connect it to your Meta Business account.
  3. Enable server-side events, or generate a Conversions API access token if the plugin asks for one.
  4. Check that each event is sent with an event ID so browser and server versions can be matched.
  5. Test events in Events Manager before running ads.

On a non-store WordPress site, such as a clinic or service business, you can send the Lead event from your form plugin or through Google Tag Manager, and add server-side events with a plugin or a server-side tagging setup. The Google Tag Manager basics guide explains the browser side.

Lead generation sites and WhatsApp enquiries

Many Indian businesses running Meta ads are not selling online at all. They want enquiries: a form, a call or a WhatsApp message. Tracking these well takes a little more thought than tracking a purchase:

  • Forms: send a Lead event only after a successful submission. With CAPI, the server can send the same event when the form is saved, which is more reliable than the browser alone.
  • WhatsApp clicks: a click on a WhatsApp button can be tracked as a Contact event, but it only shows intent. It does not tell you whether a conversation happened.
  • Calls: tap-to-call clicks can be tracked the same way, with the same limitation.
  • Lead quality: some businesses later send an offline event when a lead becomes a customer, so Meta can learn which leads matter. This needs a CRM or a careful manual process.

If you are deciding whether to send ad clicks to a WhatsApp chat or to a landing page, the guide on click-to-WhatsApp ads vs a website compares the two. Whichever you choose, keep the same events consistent across Meta and Google Analytics so the numbers can be compared. The GA4 events explained guide covers the Google side.

It is also worth agreeing in advance what counts as a lead. A form submission with a fake number is not the same as a real enquiry, and a spam-protected form keeps your ad data cleaner. Decide this with whoever runs your ads before the tracking is built, because changing event definitions later makes old and new reports hard to compare, and the ad algorithm has to learn again from the new signal.

Deduplication: the step people miss

If both the pixel and CAPI send a Purchase for the same order, Meta needs to know they are the same event. This is done by sending the same event name and the same event ID from both. Official integrations usually handle this, but custom setups often do not. In Events Manager, the overview shows whether events are being deduplicated. If purchases in Meta are noticeably higher than real orders, duplicate events are a likely cause.

Event match quality and customer data

The Conversions API can send customer details such as email or phone number, hashed before they are sent, to help Meta match events to accounts. This improves match quality, but it is personal data. Only send what you need, make sure your privacy policy explains the tracking, and follow any consent requirements that apply to your visitors. India's data protection rules are evolving, so check current obligations with your legal adviser, particularly if you also have visitors from Europe.

Testing and checking your setup

  • Use the Test Events tool in Events Manager while you browse your site and place a test order or submit a form.
  • Install the Meta Pixel Helper browser extension to check browser events.
  • Compare a week of purchases in Meta with your real orders in Shopify or WooCommerce.
  • Check that values and currency are correct, and that test orders are cancelled.
  • Recheck after theme changes, checkout changes, payment gateway changes or plugin updates.

Keeping tracking from slowing your site

Every tracking script adds weight. Load the pixel once, avoid stacking several plugins that each add their own copy, and remove tracking for platforms you no longer use. Server-side events add little or nothing to page load for visitors. If your ads bring people to landing pages, speed matters even more, since paid clicks that bounce before the page loads are wasted. The WordPress speed optimisation page covers what can be done there.

FAQs

Do I need both the Meta Pixel and the Conversions API?

Meta recommends using both. The pixel captures browser events and the Conversions API sends events from your server, which helps when browsers block tracking.

How do I set up the Meta Pixel and Conversions API on Shopify?

Connect your store through Shopify's Facebook and Instagram channel and choose the higher data-sharing setting. Remove any old pixel code from your theme to avoid duplicate events.

Can I use the Conversions API on WooCommerce?

Yes. Meta's official integration and several tracking plugins support server-side events on WooCommerce. Make sure event IDs are sent for deduplication.

Why does Meta show more purchases than my store?

Usually duplicate events, from old pixel code plus an integration, or from browser and server events that are not deduplicated.

Does the Meta Pixel slow down my website?

A single pixel has a modest impact, but several tracking plugins and duplicate scripts add up. Server-side events do not slow pages for visitors.
