Meta Pixel and Conversions API Explained for Business Websites

What the Meta Pixel and Conversions API do for Facebook and Instagram ads, which events to track, setup options on WordPress, testing, and privacy basics.

Key takeaways
  • The Meta Pixel tracks actions in the browser, while the Conversions API sends events from your server and is less affected by ad blockers.
  • Use standard events such as Lead, Contact and Purchase, install the Pixel only once, and deduplicate browser and server events with a shared event ID.
  • Respect consent, never send sensitive details in events or URLs, and remember that WhatsApp and lead form ads need tracking outside your website.

If you advertise on Facebook or Instagram, Meta will ask you to set up a Pixel and, increasingly, the Conversions API. Both send information about what people do on your website back to Meta, so it can measure your ads and show them to people more likely to enquire or buy. Here's what each one does, which events to track, how to set them up on WordPress, and what to watch for on privacy.

What the Meta Pixel does

The Pixel is a small piece of JavaScript that runs in the visitor's browser. When someone views a page, adds a product to the cart or submits a form, it sends an event to Meta. That data is used for three things:

  • Measurement: seeing which ads led to enquiries or sales, not just clicks
  • Optimisation: helping Meta show your ads to people similar to those who converted
  • Audiences: building groups such as "visited the pricing page in the last 30 days" for retargeting

Because it runs in the browser, the Pixel can be blocked by ad blockers, browser privacy features and visitors who decline cookies, so it always misses some conversions.

What the Conversions API adds

The Conversions API (often called CAPI) sends the same kinds of events from your server, or from a connected platform, directly to Meta. Because it doesn't depend on the browser, it's less affected by ad blockers and browser restrictions. It can also send events that never happen in a browser, such as an order marked as paid or a lead your team later marks as qualified.

Meta recommends using both together. The catch is deduplication: if the Pixel and your server both report the same purchase, each needs to send a matching event name and event ID so Meta counts it once. Good integrations handle this for you, but it's worth checking.

Which events to track

Meta has a set of standard events. Use them where they fit rather than inventing your own names, because Meta's ad optimisation understands them.

What happened on your siteStandard event
Any page viewedPageView
Product or service page viewedViewContent
Enquiry or quote form submittedLead
Call or WhatsApp button clickedContact
Appointment bookedSchedule
Product added to cartAddToCart
Checkout startedInitiateCheckout
Order placedPurchase, with value and currency

Fire Lead only on a successful submission (a thank-you page or form success event), not on a button click. The thinking behind choosing events is the same as for Google Analytics; see GA4 events explained.

Setup options on WordPress

  1. Official or partner integrations: Meta offers integrations for WordPress and WooCommerce, set up from Events Manager or installed as plugins. They're the quickest route and, depending on the version, can send both Pixel and Conversions API events, including WooCommerce purchases. Check current features before relying on them.
  2. Google Tag Manager: precise control over which events fire and when, handy if you already manage GA4 and Google Ads tags there. On its own this is browser-side only.
  3. Server-side tagging or Meta's Conversions API Gateway: more robust, but usually involves separate hosting and ongoing costs; mainly worth it for stores and advertisers with serious spend.
  4. Custom code: for custom forms or checkouts, a developer can send events directly, with proper deduplication.

Whichever you choose, install the Pixel only once. A Pixel added through a theme setting, a plugin and Tag Manager at the same time is a common cause of doubled numbers. Keep an eye on speed too: every marketing script adds weight, which matters on Indian mobile networks.

Test before you trust the numbers

  • Test Events in Events Manager shows events arriving from your browser and your server in real time, so you can submit a test enquiry or order and watch it come through.
  • Meta Pixel Helper, a browser extension, shows which Pixel events fire on each page.
  • Event Match Quality in Events Manager indicates how well your server events can be matched to Meta accounts; sending more customer information (hashed) generally improves it.
  • Compare with reality: check the leads or purchases Meta reports against your lead log or WooCommerce orders each month.

It's also generally recommended to verify your domain in Meta's business settings, which confirms your business owns the website.

Privacy, consent and sensitive data

The Pixel uses cookies and sends browsing data to Meta, and advanced matching can send hashed email addresses or phone numbers. So:

  • Mention Meta's tools in your privacy policy and explain how visitor data is used; see privacy policy and cookie consent basics
  • If you use a consent banner, load the Pixel only after visitors accept marketing cookies (the Pixel has a consent setting for this), and make sure server-side events respect the same choice
  • Never send sensitive details in events, URLs or page titles, such as a thank-you page URL that names a medical treatment, or a form's free-text message
  • Clinics, hospitals and financial services should check Meta's current rules, as some categories face restrictions on the data and events they can use

India's data protection rules are being phased in, and different rules may apply to overseas visitors, so check current requirements or ask a lawyer.

What about WhatsApp and lead form ads?

Many Indian businesses run ads that open a WhatsApp chat or a Meta lead form directly. Neither involves your website, so the Pixel doesn't see those conversions:

  • Click-to-WhatsApp ads: Ads Manager reports conversations started. Use WhatsApp Business labels to note which chats became customers.
  • Lead form ads: leads are collected inside Facebook or Instagram. Meta offers ways to send lead outcomes back from your CRM, so it learns which leads become customers, not just which forms get filled; check current options.

If your ads send people to a landing page instead, the Pixel and Conversions API are what connect those visits to results. The page itself matters just as much; see landing page mistakes that waste ad budget.
