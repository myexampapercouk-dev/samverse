WordPress Security Checklist for Small Business Websites (20 Steps)

A practical 20-step WordPress security checklist for small businesses: updates, passwords, 2FA, backups, firewalls, hosting and user roles, to keep your site safe from hackers.

Key takeaways
  • Keep core, themes and plugins updated and delete anything unused.
  • Use strong unique passwords, two-factor authentication and minimal user roles.
  • Run automatic off-site backups, reputable hosting and a firewall, and monitor Search Console.

Most hacked WordPress sites aren't targeted personally. Automated bots scan millions of websites looking for known weaknesses like outdated plugins and weak passwords. The good news is that a handful of basic steps block the vast majority of these attacks. Use this checklist to secure your business website.

Updates and software

  1. Keep WordPress core updated. Minor security releases often install automatically; apply major updates after a backup.
  2. Update plugins and themes promptly. Outdated plugins are the most common way into WordPress sites.
  3. Delete unused plugins and themes. Deactivated code can still be exploited if it's vulnerable.
  4. Avoid abandoned plugins. If a plugin hasn't been updated in a long time, look for a maintained alternative.
  5. Never use "nulled" (pirated) themes or plugins. They frequently contain hidden malware.
  6. Run a current PHP version supported by your host.

Worried updates will break things? Follow this safe update process.

Logins and users

  1. Use strong, unique passwords for every admin, with a password manager.
  2. Turn on two-factor authentication (2FA) for all administrator accounts.
  3. Limit login attempts to slow down password-guessing bots.
  4. Don't use "admin" as a username.
  5. Give people the lowest role they need. Editors and authors don't need administrator access.
  6. Remove old users such as former staff, agencies and freelancers once their work is done.

Not sure which role to give whom? See WordPress user roles explained.

Backups

  1. Automatic daily backups of files and database.
  2. Store backups off-site (cloud storage), not only on the same server.
  3. Test restoring a backup occasionally. An untested backup might fail when you need it.

More on getting backups right: WordPress backup and restore.

Hosting and server

  1. Choose reputable hosting with malware scanning, firewalls and account isolation.
  2. Use HTTPS everywhere with a valid SSL certificate.
  3. Use SFTP, not FTP, and secure your hosting control panel with 2FA.

An extra layer: website security headers explained.

Monitoring and protection

  1. Install a reputable security plugin or firewall to block malicious traffic and scan for malware.
  2. Monitor Google Search Console for security warnings, and set up uptime monitoring so you know quickly if the site goes down.

Keep your plugin list lean and well maintained; see essential WordPress plugins (and ones to avoid).

Signs something is already wrong

Unexpected redirects, strange pages in Google results, unknown admin users or browser warnings are signs of an existing infection. See our guide to the signs of a hacked WordPress site, and get it cleaned properly before hardening.

Make security routine

Security isn't a one-time task. Updates, backups and checks need to happen every month. Many businesses put their site on a maintenance plan so this happens consistently without them having to remember.
