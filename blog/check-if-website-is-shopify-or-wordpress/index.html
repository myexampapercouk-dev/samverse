How to Check if a Website Is Shopify or WordPress (6 Quick Ways, No Tools Needed)

Tell if any site runs on Shopify or WordPress in under a minute: URL patterns, page source, /wp-admin and /admin, cdn.shopify.com, and lookup tools.

Key takeaways
  • View the page source: /wp-content/ or wp-json means WordPress, cdn.shopify.com or Shopify.theme means Shopify.
  • URL patterns, the /wp-admin or /admin login address, the browser console and lookup tools such as Wappalyzer confirm it.
  • Headless setups and shops on subdomains can show both or neither, so check the checkout and subdomains too.

You can tell whether a website is Shopify or WordPress by viewing its page source: WordPress sites load files from /wp-content/ or /wp-includes/, while Shopify stores load files from cdn.shopify.com and have a Shopify JavaScript object on the page.

That one check settles most cases. The other methods below help when a site hides the obvious signs, and the last section explains what the answer tells you if you're choosing a platform yourself.

Six ways to check

  1. Look at the page source. On a computer, right-click the page and choose View page source (or press Ctrl+U). Press Ctrl+F and search for:
    • wp-content or wp-json: WordPress.
    • cdn.shopify.com or Shopify.theme: Shopify.
    • woocommerce in class names or file paths: WordPress with WooCommerce.
  2. Read the URLs. Shopify stores use fixed paths: /products/, /collections/, /pages/ and /cart. WooCommerce often uses /product/ (singular) and /product-category/, and WordPress blogs often have dates or /category/ in addresses. URLs alone are a hint, not proof, because both platforms can be customised.
  3. Try the login address. Add /wp-admin or /wp-login.php to the domain. A WordPress login screen confirms WordPress. Adding /admin to a Shopify store usually redirects to a Shopify login page on a shopify.com address. Don't try to log in; just look at where it lands.
  4. Check WordPress-only files. yourdomain.com/wp-json/ returns a block of JSON on most WordPress sites, and /license.txt may show the WordPress licence. Security plugins sometimes block these, so a missing file doesn't prove it isn't WordPress.
  5. Check the browser console on a Shopify suspect. Press F12, open Console, type Shopify and press Enter. On a Shopify store it returns an object with the shop's details; elsewhere it says "not defined".
  6. Use a lookup tool. Browser extensions such as Wappalyzer, or BuiltWith's free website lookup, list the platform, theme and many apps or plugins in one click. They are quick but occasionally wrong on heavily customised sites.

On a phone

Mobile browsers don't show page source easily. The quickest checks are the address tricks: add /wp-admin or /admin, or look at product URLs for /products/ and /collections/. In Chrome on Android you can also type view-source: before the address to see the source.

When the answer is "neither" or "both"

  • Headless sites. Some brands use Shopify for checkout with a custom front end, or WordPress only for content behind a JavaScript site. You may see Shopify only at checkout (checkout.shopify.com or a /checkouts/ path) and nothing on the home page.
  • Shop on a subdomain. A WordPress site at example.com with a Shopify store at shop.example.com is common. Check both.
  • Other platforms. Wix pages load from static.wixstatic.com, Squarespace from squarespace-cdn.com, and Webflow from website-files.com or similar Webflow addresses.
  • Behind Cloudflare. A CDN hides the server, but not the files the page loads, so the page source check still works.

What the answer tells you about the business

If you're checking competitors to choose a platform, copying their choice isn't enough on its own. Brands on Shopify usually wanted hosting, security and checkout handled for a monthly fee. Businesses on WordPress or WooCommerce usually wanted lower running costs, more control over content and SEO, or Indian payment and shipping setups without app fees. FAQs

Can a website use both Shopify and WordPress?

Yes. A common setup is WordPress for the blog and main pages with a Shopify store on a subdomain, or the Shopify Buy Button embedded in WordPress pages.

Can a site hide that it uses WordPress?

It can remove the generator tag and block some files, but the theme and plugin files almost always still load from /wp-content/, so the page source usually gives it away.

How do I find which Shopify theme a store uses?

In the page source search for Shopify.theme. The line shows a theme name, though stores often rename their theme, so it may not match the theme store name.
