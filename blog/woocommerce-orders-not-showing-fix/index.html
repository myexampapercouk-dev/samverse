WooCommerce Orders Not Showing? Missing Orders, Paid-but-No-Order and Missing Emails

WooCommerce orders not showing? Find missing orders, fix paid-but-no-order problems, HPOS sync issues, pending payment filters and missing order emails.

Key takeaways
  • Many "missing" WooCommerce orders are hidden by status filters, pending payment, drafts or HPOS sync settings rather than truly lost.
  • Paid-but-no-order problems usually mean the payment gateway callback failed, so compare the gateway dashboard with WooCommerce and check logs.
  • Missing order emails are a separate issue, normally fixed with proper SMTP setup and checking the email settings for each order status.

If WooCommerce orders are not showing, first check the order list filters and the "Pending payment" and "Drafts" views, then check whether your store uses HPOS (High-Performance Order Storage) and whether sync is set correctly. If a customer has paid but no order exists, the payment gateway's callback probably failed. If orders exist but nobody received the email, that is an email delivery problem, not a missing order.

This guide separates those three problems and walks through how to fix each.

WooCommerce orders not showing in admin: quick checks

  1. Check "All" orders, not just Processing. Orders on Pending payment, On hold, Failed or Cancelled are easy to miss.
  2. Clear filters and search, including date and customer filters left from earlier.
  3. Check the Drafts or checkout-draft view. The block-based checkout creates draft orders before payment; these are not real orders until completed.
  4. Search by order number, email and phone.
  5. Clear the object cache if your host uses Redis or Memcached, and make sure admin pages are not page-cached.
  6. Check user role: a shop manager account with restricted capabilities, or a plugin that limits order access, can hide orders.

HPOS and order sync issues

Newer WooCommerce versions store orders in their own database tables (HPOS) instead of the old posts table. During or after migration, mismatches can make orders appear missing in one place:

  • Go to WooCommerce, Settings, Advanced, Features and check which order storage is authoritative.
  • Check whether compatibility mode (sync between old and new tables) is enabled and whether sync is pending.
  • Some older plugins read orders from the old table only. If a plugin, report or app shows fewer orders, it may not support HPOS yet. Check its documentation and update it.
  • Do not switch storage modes on a live store without a full backup and a test on staging.

The WordPress backup and restore guide covers taking a safe backup first, and staging sites explains testing changes.

Paid but no order: the gateway callback

When a customer pays through Razorpay, Cashfree, PayU or another gateway, the gateway must tell WooCommerce the payment succeeded. If that message fails, you can get a payment with no order, or an order stuck on Pending payment.

  1. Find the payment in the gateway dashboard and note the payment ID, email and time.
  2. Search WooCommerce for the same email and time, including Pending payment and Failed.
  3. Check the gateway's webhook logs for failed deliveries to your site.
  4. Check WooCommerce, Status, Logs for gateway and fatal error logs around that time.
  5. Check firewall, security plugin and Cloudflare rules that might block the gateway's requests.

If the order exists as pending, confirm the payment in the gateway and update the status manually with a note. If there is no order at all, create it manually or refund, depending on what you and the customer agree. Checkout errors that stop orders being created

Sometimes the checkout fails before an order is created, often after an update. Signs include a spinning checkout button, a blank error message or customers saying they could not complete purchase.

  • Check the browser console on checkout for JavaScript errors.
  • Check the PHP error log and WooCommerce fatal error log.
  • Exclude cart, checkout and my-account pages from caching and script optimisation.
  • Test for plugin conflicts on staging; troubleshooting plugin conflicts explains how.

Order emails not arriving

If orders exist but you or the customer did not get the email:

  • Go to WooCommerce, Settings, Emails and check that New order, Processing order and Completed order emails are enabled with the right recipient.
  • Remember the customer email is sent when the order moves to Processing, so pending orders will not trigger it.
  • Set up proper SMTP sending with an authenticated mailbox or email service instead of the server's default mail. WordPress not sending emails covers this.
  • Check SPF, DKIM and DMARC for your domain; email deliverability explains them.
  • Use an email log plugin to see whether emails were sent and failed, or never sent.

Many stores also add SMS or WhatsApp order notifications so the owner never misses a new order.

Customers cannot see orders in My Account

This usually happens when the order was placed as a guest, or with a different email from the account. Assign the order to the customer account from the order edit screen. Consider requiring account creation or linking guest orders by email, if it suits your store.

Orders missing from apps, reports and integrations

Sometimes orders are fine in WooCommerce but missing elsewhere: the mobile app, analytics reports, a shipping tool such as Shiprocket, an accounting sync or a CRM. Each has its own causes:

  • WooCommerce Analytics: reports use their own data that is imported and cached. Check the analytics settings for excluded statuses, and use the option to re-import historical data if numbers look wrong.
  • Shipping and courier integrations: many only pull orders with certain statuses, such as Processing. Orders on hold or pending will not appear until their status changes. Check the integration's status settings and connection.
  • REST API and webhooks: integrations often rely on WooCommerce webhooks or API keys. A disabled webhook, expired key or security rule blocking requests stops orders syncing. WooCommerce, Settings, Advanced lists webhooks and their status.
  • HPOS compatibility: older integrations may not read orders from the new tables.

A quick test is to change a test order's status manually and see whether it appears in the integration. If it does, the integration only reads certain statuses; if it does not, the connection itself is broken. When a single integration is the problem, check its own logs and support documentation before changing WooCommerce settings.

Scheduled tasks and stuck statuses

WooCommerce uses scheduled actions for tasks such as cancelling unpaid orders, sending some emails and syncing data. If WP-Cron is not running reliably, these tasks pile up and orders can sit in the wrong status. Check WooCommerce, Status, Scheduled Actions for many past-due or failed actions. WordPress cron explained covers how to set up a real server cron job so tasks run on time even on low-traffic stores.

Also review the "Hold stock" setting under WooCommerce, Settings, Products, Inventory. If it is too short, unpaid orders may be cancelled before slower payments such as UPI or net banking complete, which looks to the customer like their order disappeared.

Preventing missing orders

  • Back up before every WooCommerce, plugin or storage change.
  • Test a real order after updates.
  • Monitor gateway webhooks and fix failed deliveries.
  • Use SMTP and an email log.
  • Review orders against gateway payments regularly, especially pending ones. An order management workflow helps make this routine.

Getting help

Missing orders mean missed shipments and unhappy customers. A WooCommerce developer can trace the cause through logs, gateway records and settings and fix it properly. You can also hire a WooCommerce developer in India for ongoing store maintenance.

Whatever the cause turns out to be, write down what happened, what you checked and what fixed it. A short incident note saves a lot of time if the same problem appears after a future update, and it gives a developer a useful starting point if you need outside help. Keep a list of orders you corrected manually so you can check they were shipped and invoiced properly.

FAQs

Why are WooCommerce orders not showing in my dashboard?

Usually because of status filters, pending payment or draft views, HPOS sync settings, caching or user role limits. Check All orders and clear filters first.

A customer paid but there is no order. What happened?

The gateway likely failed to notify WooCommerce, or checkout failed after payment. Compare the gateway dashboard with WooCommerce and check webhook and error logs.

What is HPOS in WooCommerce?

High-Performance Order Storage keeps orders in dedicated tables. If a plugin does not support it, that plugin may not show all orders.

Why am I not getting new order emails?

Check email settings in WooCommerce, then set up SMTP and an email log. Many hosts' default mail sending is unreliable.

Can I recover missing WooCommerce orders?

If the order exists in the database, yes, by fixing filters or sync. If it was never created, you can create it manually from the gateway payment details.
