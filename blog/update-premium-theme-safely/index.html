How to Update a Premium WordPress Theme Safely: Licences, ZIP Uploads, Bundled Plugins and Keeping Your Customisations

How to update a premium WordPress theme safely: licence updates or ZIP upload, backup, staging, child themes, bundled plugins and fixing a broken update.

Key takeaways
  • Premium themes only update automatically once the licence or purchase code is activated; otherwise download the latest ZIP from the vendor and upload it with "Replace current with uploaded".
  • Before updating, take a full backup and check whether anyone edited the theme files directly, because those edits are overwritten; move them into a child theme first.
  • Update the theme, then its bundled plugins, then test key pages, forms and checkout, ideally on staging first when the version jump is large.

To update a premium WordPress theme safely, take a full backup, check that nobody has edited the theme's own files, then update it through the vendor's licence (activate your licence or purchase code and the update appears in Dashboard > Updates) or by downloading the latest ZIP from your account and uploading it under Appearance > Themes > Add New Theme > Upload Theme. For a big version jump, test it on a staging copy first, and update the theme's bundled plugins straight afterwards.

Theme and plugin updates are part of my WordPress maintenance plans, and I can include premium themes and their bundled plugins, with a backup taken first and the site tested afterwards. If you'd rather do it yourself, the steps are below.

This guide is specific to premium themes. For updating WordPress core and ordinary plugins, see how to update WordPress safely.

Why premium themes don't update like free ones

Free themes from the WordPress.org directory update straight from the dashboard. Premium themes are sold by their developers or through marketplaces such as ThemeForest, and WordPress only learns about a new version once the theme can check with the vendor, which normally needs a licence key, purchase code or account token. If that was never set up, or the licence has lapsed, the site can sit on an old version for years without anyone noticing.

No update notice for the theme or a plugin? An inactive licence is one cause, but there are others; see why the WordPress update button is missing.

Before you update: four checks

  1. Is a child theme active? Appearance > Themes shows which theme is active. If it's a child theme, your customisations are probably safe in it, and the parent can be updated.
  2. Has anyone edited the parent theme's files? Edits made directly in the parent theme, through the Theme File Editor or over FTP, are overwritten by an update. If you're not sure, download the same version you're running from the vendor and compare the folders.
  3. How big is the jump? Read the changelog. Major versions, minimum PHP and WordPress requirements and any notes about bundled plugins tell you how careful to be.
  4. Do you have a backup you can restore? Back up files and database, store a copy off the server, and know how to restore it; see the WordPress backup and restore guide.

With SSH access, a quick way to spot direct edits is to compare the live theme with a fresh copy of the same version. Any file listed as different has been changed:

wp theme list
diff -rq wp-content/themes/yourtheme ~/fresh-copy/yourtheme

Step by step: updating a premium theme

Option 1: one-click update with the licence

Activate your licence or purchase code in the theme's dashboard screen. Within a short while, the update appears under Dashboard > Updates and on the Themes screen, and you update it like any other theme.

Option 2: upload the new ZIP

  1. Log in to your account with the vendor or marketplace and download the latest version. On ThemeForest, choose the installable WordPress file only, not the full package with documentation.
  2. Go to Appearance > Themes > Add New Theme > Upload Theme, choose the ZIP and click Install Now.
  3. WordPress notices the theme is already installed and shows the current and uploaded versions side by side. Click "Replace current with uploaded".

If the upload fails because the file is too large, ask your host to raise the upload limit or use the next option.

Option 3: replace the folder over SFTP or WP-CLI

Rename the current theme folder (for example yourtheme to yourtheme-old), upload the new folder in its place, and check the site. If something goes badly wrong, renaming the folders back restores the old version in seconds. Delete the old folder once you're happy. With WP-CLI, the same replacement is one command:

wp theme install ~/downloads/yourtheme.zip --force

After the theme: the right order

  1. Update the theme's bundled plugins when the theme prompts you, usually from its own plugins screen
  2. Update your other plugins
  3. Regenerate your page builder's CSS if it has that option, and clear every cache: plugin, server and CDN
  4. Test the site, as below

Test on staging first for big version jumps

A minor update on a simple site can usually go straight to live after a backup. Use a staging copy first when the theme is a major version or more behind, the site is a WooCommerce store, or the theme overrides templates that you or a developer customised. Many hosts offer one-click staging; see staging sites explained.

Bundled plugins: the part people forget

Many premium themes ship with premium plugins included, typically a slider, a page builder and a "theme core" plugin that adds the theme's features. You usually can't update these with their own licence, because you never bought one. They arrive through theme updates instead, which means an outdated theme often leaves outdated plugins behind it, and bundled sliders and builders have had serious security holes in the past.

  • After updating the theme, install the bundled plugin updates it offers straight away
  • Delete bundled plugins the site doesn't actually use
  • If a bundled plugin has a known vulnerability and the theme hasn't shipped a fix, buy your own licence for that plugin so you can update it directly, or replace it

Bundled plugins are one of the trade-offs covered in what to know before buying a premium theme.

If you find edits in the parent theme

Don't update until they're moved. Create a child theme, then move each change to the right place: CSS into the child theme's style.css or the Customizer's Additional CSS, PHP functions into the child theme's functions.php or a small custom plugin, and edited template files into the child theme at the same path. Then update the parent.

Switching an existing site to a child theme can reset some Customizer settings and menu locations, so note or export them first and do the switch on staging. WordPress child themes explained has the setup code.

If something breaks after the update

  • Roll back first, investigate second. Restore the backup, or swap the old theme folder back if you used Option 3, so the live site works while you find the cause.
  • Check the usual suspects: page builder CSS that needs regenerating, a cache that wasn't cleared, a bundled plugin that wasn't updated, or a PHP version the new theme doesn't support.
  • Read the error. A "critical error" screen comes with a recovery-mode email to the admin address that usually names the file at fault.
  • Contact the theme's support with your licence, the old and new version numbers and what broke. Support usually needs a valid licence.

General rollback plugins work with themes from the WordPress.org directory, not with most premium themes. A few vendors build a rollback option into the theme itself, but usually your backup is the rollback.

When the theme is abandoned or the licence has expired

If the theme hasn't been updated in a long time, doesn't support current PHP versions, or the vendor has disappeared, updating isn't an option and the risk grows every month. Renew the licence if the theme is still maintained. If not, the choice is between moving to a well-maintained, lightweight theme while keeping your design, or a planned website redesign. Whatever you do, don't download "free" copies of the theme from unofficial sites: those nulled copies are a common source of malware; see the risks of nulled themes and plugins.

FAQs

How do I update a premium WordPress theme without losing customisations?

Make sure your customisations live in a child theme, the Customizer or the theme's own settings, not in the parent theme's files. Settings stored in the database survive updates; direct edits to theme files don't. Back up, then update.

How do I update a ThemeForest theme?

Either register the theme with your purchase code or an Envato token, using the theme's own registration screen or the Envato Market plugin, so updates appear in the dashboard, or download the installable WordPress file from your ThemeForest downloads and upload it with "Replace current with uploaded".

Will updating my theme delete my pages or content?

No. Pages, posts, products and images are stored in the database and the uploads folder, which a theme update doesn't touch. What you can lose is direct edits to the theme's files, and occasionally layouts can look different until builder CSS is regenerated.

Can I update a premium theme without a licence?

Without an active licence you won't get automatic updates, and some vendors also stop downloads. If you still have access to the account that bought it, you may be able to download the latest version manually. Never use a nulled copy from an unofficial site.

Do I need to update the bundled plugins separately?

Usually yes. Bundled plugins update through the theme, typically from a plugins screen the theme adds, after the theme itself is updated. Check them every time you update the theme.
