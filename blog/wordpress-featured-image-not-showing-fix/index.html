WordPress Featured Image Not Showing? Fixes for Posts, Blog Pages, Thumbnails and Social Shares

WordPress featured image not showing on posts, the blog page or Facebook and WhatsApp shares? Fix theme settings, sizes, lazy loading, caches and OG tags.

Key takeaways
  • Most missing featured images are a theme or template setting, not a broken image: check the theme options and the post template first.
  • Blurry, cropped or blank thumbnails usually need image sizes regenerated, or a lazy loading or cache setting excluded.
  • Wrong or missing images on WhatsApp and Facebook shares come from Open Graph tags and cached previews, not from the post itself.

If your WordPress featured image is not showing, first check whether one is actually set in the post sidebar, then check your theme's settings, because many themes let you hide featured images on single posts, archives or both. If the image is set and enabled but the space is blank, broken or blurry, the cause is usually missing image sizes, a lazy loading or CDN setting, or a page builder template that doesn't include the featured image. Wrong images on WhatsApp or Facebook shares are a separate issue with Open Graph tags.

Fix 1: Confirm the featured image is set and the panel is visible

Open the post, click the Post tab in the right sidebar and look for Featured image. If the panel is missing, open the three-dot menu, choose Preferences, then Panels, and switch Featured image on. Set or replace the image and click Update.

On custom post types such as portfolio items, services or team members, the panel only appears if the post type was registered with thumbnail support. If it's missing there, the developer who built the post type needs to add it.

Fix 2: Check the theme's featured image settings

Most themes have switches for featured images in Appearance > Customize, usually under Blog, Single Post or Post Layout. Look for options such as "Show featured image", "Post header layout" or "Image position". It's common for a theme to show the image on the blog page but hide it on the post itself, or to place it behind the title as a background where it's easy to miss.

Block themes control this in the template. Go to Appearance > Editor > Templates, open Single Posts, and check that a Featured Image block is present. For the blog page, open the Blog Home or Index template and check the Post Featured Image block inside the Query Loop.

If you've changed theme recently, expect these settings to need setting again, so check a single post and the blog page straight after any switch.

Fix 3: Page builder templates

When Elementor or another builder controls single posts or archives, the theme's settings no longer apply. Edit the single post template and make sure it contains the builder's Featured Image widget, and that the Posts or Loop widget on archive templates has "Image" switched on. Also check the template's display conditions, so it's applied to all posts rather than one category.

Fix 4: Blank, broken or missing images

Right-click the empty space, choose Inspect, and find the img tag. Copy the image URL and open it in a new tab.

  • The image opens: the file is fine, so lazy loading, CSS or a script is hiding it. Go to Fix 6.
  • 404 error: the file is missing. This is common after a migration or a cleanup plugin deleted "unused" sizes. Re-upload it, or regenerate thumbnails if the original exists.
  • The URL uses http or the old domain: the site moved and the database still points at old addresses. A search-and-replace of the old URL fixes it; take a backup first. For the http case, also check for mixed content warnings.

If images also fail to load in Media > Library, follow the media library not loading fixes first, because the cause is shared.

Fix 5: Blurry, stretched or wrongly cropped thumbnails

When you upload an image, WordPress creates several resized copies at the sizes your theme asks for. Change the theme, or its image settings, and old images don't get new sizes automatically. The theme then falls back to the nearest size, which can look blurry or cropped.

  1. Install a thumbnail regeneration plugin and regenerate all sizes, ideally outside business hours on a large library.
  2. Upload featured images at the width your theme suggests, usually at least 1200 pixels wide for full-width post headers, and keep the same aspect ratio across posts.
  3. Check Settings > Media and the theme's image size settings if crops are still wrong.

The image SEO guide covers file names, formats and alt text, which matter for featured images because Google and social apps reuse them.

Fix 6: Lazy loading, CDN and cache conflicts

Speed plugins often replace image addresses with placeholders and swap in the real image with JavaScript. If that script is delayed or broken, the featured image never appears. Excluding the first image on the page from lazy loading is also good practice, because it is usually the largest element above the fold.

  • Temporarily switch off lazy loading in your speed or caching plugin and test. If the image returns, exclude featured images or the first image from lazy loading.
  • If you use a CDN or image optimisation service, check whether the image URL points at the CDN and loads there. Purge the CDN cache.
  • Clear all caches after any fix, then test in a private window.

Lazy loading explained shows what to exclude and why. If you've changed the image and the old one still appears, WordPress changes not showing walks through each cache layer.

Fix 7: Featured image not showing on WhatsApp, Facebook or LinkedIn

When you share a post link, the app reads the page's Open Graph tags (og:image) to pick a preview image. If the preview is missing or shows your logo instead:

  • Make sure only one plugin outputs Open Graph tags. Yoast SEO, Rank Math, All in One SEO and some themes and social plugins all can; two sets of tags confuse the apps.
  • In your SEO plugin's social settings, set a default image and check the post's own social image, which overrides the featured image.
  • Use an image at least 1200 by 630 pixels, under a few hundred KB, in JPG or PNG, and not blocked by a firewall or hotlink protection.
  • Previews are cached. Facebook's Sharing Debugger and LinkedIn's Post Inspector let you refresh them. WhatsApp keeps its own cache for a while; sharing the link with a harmless query string such as ?v=2 shows a fresh preview.

Logo, favicon and brand basics covers default social share images, so posts without their own still share well.

Preventing featured image problems

  • Agree a standard size and ratio for featured images and stick to it.
  • Compress before uploading, but don't upload tiny images; WordPress can't make small images sharp.
  • After a theme change, migration or speed plugin change, check a single post, the blog page and a share preview. After moving to HTTPS, also follow the mixed content fixes, because http image URLs are a common cause of missing images.

Quick check: theme, setting or cache?

  1. Open the post in the editor and confirm a featured image is set in the Post settings panel.
  2. Check your theme's options (often under Appearance > Customize) for a "show featured image" setting on single posts or archives.
  3. Clear your cache and test the page in a private window. For social shares, test the URL in the Facebook Sharing Debugger, which reads the og:image tag.

FAQs

Why is my WordPress featured image not showing?

Usually the theme hides it on single posts or archives, a page builder template doesn't include it, or no featured image is set. Check the post sidebar, the theme's Customizer settings and any builder templates.

Why is my featured image not showing on the blog page?

The blog or archive layout has images switched off, or a builder's posts widget has the image option off. In block themes, check that the Query Loop in the blog template contains a Post Featured Image block.

Why is the featured image option missing in WordPress?

The panel may be hidden in the editor's Preferences, or the post type was created without thumbnail support. Switch the panel on in Preferences > Panels, or ask a developer to add support to the custom post type.

Why does my featured image look blurry?

The image is smaller than the space the theme gives it, or WordPress is serving an old size after a theme change. Upload a larger image and regenerate thumbnails.

Why is my featured image not showing when I share on WhatsApp?

WhatsApp reads the og:image tag, and caches previews. Check that one SEO plugin outputs a correct og:image of a suitable size, then share the link with a query string to see a fresh preview.

Does the featured image affect SEO?

Indirectly. Google can use it in Discover and search results, and social apps use it for previews, which affects clicks. Use a relevant, well-sized image with a descriptive file name and alt text.
