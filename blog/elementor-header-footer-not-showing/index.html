Elementor Header or Footer Not Showing? How to Fix Theme Builder Templates That Do Not Appear

Elementor header or footer not showing on your site? Fix display conditions, theme support, Pro licence issues and caching, with the checks in the right order.

Key takeaways
  • An Elementor Theme Builder header or footer that does not appear is usually missing display conditions, unpublished, or blocked by a theme that does not support Elementor locations.
  • Check in this order: template published, conditions set to Entire Site, Elementor Pro active and licensed, theme support, then caches and conflicting templates.
  • The Hello Elementor theme or a theme with full Theme Builder support avoids most header and footer problems.

If your Elementor header or footer is not showing, first open Templates, Theme Builder and check the template is published and has a display condition such as Entire Site. A header saved as a draft, or published without conditions, will never appear. If the conditions are correct, check that Elementor Pro is active and that your theme supports Elementor header and footer locations.

Those three checks fix most cases. The rest of this guide covers what to do when they do not, including duplicate headers, a theme header showing instead of yours and footers that vanish only on some pages.

Quick fix: check these first

  1. Go to Templates, Theme Builder, Header (or Footer). Confirm the template status is Published, not Draft.
  2. Hover the template and choose Edit Conditions. Add Include, Entire Site, unless you want it only on some pages.
  3. Go to Plugins and confirm Elementor Pro is active. Theme Builder templates do not work with the free plugin alone.
  4. Go to Elementor, Tools and use Regenerate CSS and Data, then clear your caching plugin, server cache and CDN.
  5. Open the page in a private tab to see what logged-out visitors see.

Why the Elementor header or footer is not showing

1. Display conditions are missing or too narrow

Every Theme Builder template needs conditions that tell Elementor where to use it. When you publish a new header, Elementor asks for conditions; if you close that window, the template is published but used nowhere. Conditions can also be narrower than you think, for example only the front page, only posts or only a single page that has since been deleted.

Also check exclusions. An Exclude rule for a page, a category or the 404 page removes the header there. If the header vanishes on blog posts or WooCommerce pages only, look for exclusions or a separate template that wins for those page types.

2. Another template has higher priority

When two headers have conditions that overlap, Elementor uses the more specific condition. A header for Singular, Page will beat an Entire Site header on pages. If an old test header exists with a specific condition, it may be the one showing, or it may be blank. Review every template under Theme Builder, delete or unpublish the ones you no longer use and keep one clear default.

3. Elementor Pro is inactive, expired or out of step

Theme Builder is a Pro feature. If Elementor Pro is deactivated, removed during a cleanup or broken by an update, custom headers and footers stop appearing and the theme default header returns. An expired licence normally keeps existing templates working but stops updates; a mismatched pair of Elementor and Elementor Pro versions can cause errors. Keep both plugins up to date together. If you are unsure whether Pro is worth keeping, read is Elementor Pro worth it.

4. The theme does not support Elementor locations

Elementor replaces the header and footer through theme locations. Hello Elementor, Astra, GeneratePress, Kadence, OceanWP and many other popular themes support this. Some older or bundled premium themes do not, so the theme header prints and the Elementor one never appears, or both appear. Options:

  • Switch to a theme with full support, such as Hello Elementor (test on staging first).
  • Use the theme setting that disables its own header and footer, if it has one.
  • Ask a developer to register the Elementor locations in a child theme.

See the best theme for Elementor for a comparison of how each theme works with Theme Builder.

5. Page settings hide the header

In the page editor, Page Settings, Page Layout set to Elementor Canvas removes the header and footer on that page. This is useful for landing pages but confusing if someone set it by mistake. Switch to Default or Elementor Full Width. Some themes also have a per-page option such as Disable Header in their own meta box under the editor.

6. Caching and optimisation

A header published a moment ago may not show because the page cache still holds the old version. Optimisation plugins that combine CSS or delay JavaScript can also break sticky headers, menus and mobile dropdowns, so the header appears to be missing when it is actually hidden or collapsed. Clear caches and test with optimisation features turned off. WordPress changes not showing covers each cache layer in detail.

7. A plugin conflict or PHP error

If the header area is blank and the rest of the page loads, a PHP error inside a widget or a plugin conflict may be stopping output. Turn on debug logging on staging and check for errors, or deactivate plugins one at a time. Our guide to troubleshooting plugin conflicts shows a safe order. If the whole site shows a critical error message, fix that first, because the header problem is only a symptom.

Elementor footer not showing on some pages

When the footer is missing only on certain pages, compare a working page with a broken one:

  • Is the broken page using the Canvas layout or a different page template?
  • Is it a WooCommerce page, archive, search page or 404 page with its own condition?
  • Is the page very long, with a section that has a broken HTML widget or an unclosed tag that swallows the footer?
  • Is a popup or full-height section covering the footer?

An HTML or shortcode widget with broken markup is a common hidden cause. Remove recently added custom HTML and check again.

Elementor header not showing on mobile

If the header appears on desktop but not on phones, open the header template in the mobile view and check Advanced, Responsive for Hide on Mobile on the container or widgets. Some headers use a separate mobile container that was hidden or deleted. Also check the sticky settings: a sticky header with an offset or a transparent background over a white section can look missing. Finally, test with optimisation plugins paused, because delayed scripts can stop the mobile menu toggle from rendering until the visitor scrolls or taps.

Where both a desktop header and a separate mobile header exist, consider merging them into one responsive container. One header is simpler to keep correct after updates.

Elementor header showing twice

Two headers usually means the theme header and the Elementor header are both printing. The theme does not fully support Elementor locations, or a theme option to hide its header has been turned back on after an update. Turn off the theme header in its settings, or switch to a theme with proper support. If two Elementor headers appear, check for a header widget placed inside page content as well as a Theme Builder header.

How to prevent header and footer problems

  • Keep one default header and one default footer, with clear names and Entire Site conditions.
  • Name special templates by purpose, such as Landing page header, so others know why they exist.
  • Update Elementor and Elementor Pro together, on a staging site first.
  • After updates, check the home page, a blog post, a shop page and the contact page.
  • Follow a safe WordPress update routine with a backup before each update.

If the problem started straight after an update and more than the header is broken, see Elementor layout broken after an update.

When to get help

If templates look correct but the header still does not appear, the cause is usually in the theme or custom code. An Elementor developer can rebuild the Theme Builder setup cleanly, move the site to a supported theme and test every page type. FAQs

Why is my Elementor header not showing?

The usual causes are a header template that is still a draft, no display conditions, Elementor Pro being inactive or a theme that does not support Elementor header locations. Check Theme Builder conditions first, then Pro, then the theme.

How do I set an Elementor header for the entire site?

Go to Templates, Theme Builder, Header, hover your template and choose Edit Conditions. Add Include, Entire Site and save. Remove or unpublish older headers with overlapping conditions.

Why is my Elementor footer not showing on some pages?

Check whether those pages use the Elementor Canvas layout, have their own template conditions or exclusions, or contain an HTML widget with broken markup. Compare a working page with a broken one.

Do I need Elementor Pro for a custom header and footer?

For Theme Builder headers and footers, yes. The free plugin can build page content, and some themes offer their own header builder, but Elementor Theme Builder templates need Elementor Pro.

Why does my site show two headers?

The theme header and the Elementor header are both printing. Turn off the theme header in its settings or switch to a theme that fully supports Elementor locations, such as Hello Elementor.

Can a developer fix my Elementor Theme Builder setup?

Yes. A developer can check conditions, theme support, Pro versions and custom code, clean up duplicate templates and test every page type on staging before making changes live.
