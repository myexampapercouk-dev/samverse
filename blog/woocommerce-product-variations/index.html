WooCommerce Product Variations: How to Set Up Sizes, Colours, Stock and Swatches

How to set up WooCommerce product variations: attributes vs variations, global attributes, bulk editing, variation images, swatches, stock, SKUs and SEO.

Key takeaways
  • Attributes (size, colour) and their terms combine into variations, and each variation can have its own price, SKU, stock and image; use global attributes for anything shoppers filter by.
  • Generate only the combinations you sell, use bulk actions or CSV import for large catalogues, and add swatches and size charts so shoppers pick the right option first time.
  • Above WooCommerce's AJAX variation threshold (30 by default at the time of writing) unavailable combinations are no longer greyed out in advance, so keep variation sets lean and keep one URL per product for SEO.

If you sell a T-shirt in five sizes and four colours, you don't want 20 separate products. WooCommerce's variable products let customers choose options on one product page, and each combination, called a variation, can have its own price, SKU, stock level and image.

The quick version: set the product type to "Variable product", add attributes such as Size and Colour, tick "Used for variations", generate the variations, then give each one a price, SKU, stock and image. A variation with no price won't be sold, so don't skip that step. The rest of this guide covers each step properly, plus bulk editing, swatches, performance limits and SEO.

Attributes vs variations

The terms get mixed up, so it helps to be precise:

TermWhat it isExample
AttributeAn option typeSize, Colour, Material
TermA value of an attributeS, M, L or Red, Blue
VariationOne purchasable combination of termsMedium, Blue

Attributes can also be purely descriptive. A "Fabric: Cotton" attribute that isn't used for variations simply shows in the Additional information tab and, if it's global, can power filters. Only attributes ticked as "Used for variations" create choices for the shopper.

Global vs custom attributes

Global attributesCustom attributes
Where you create themProducts, then Attributes, with terms configured onceInside a single product
Reusable across productsYesNo, typed per product
Usable in shop filtersYesGenerally no
Best forSize, colour, material and anything shoppers filter byOne-off options, like a specific engraving style

Use global attributes for common options. They keep spelling consistent ("Navy" rather than "navy blue" on one product and "Navy Blue" on another), and they are what attribute filters rely on; see WooCommerce product filters.

How to set up a variable product, step by step

  1. Create global attributes. Go to Products, then Attributes, add Size and Colour, and configure their terms.
  2. Choose the product type. On a new product, set Product data to "Variable product".
  3. Add attributes. In the Attributes tab, add each attribute, select the terms this product uses, tick "Visible on the product page" and "Used for variations", then save attributes.
  4. Create variations. In the Variations tab, use "Generate variations" to create every combination, or add them manually if you only sell some. WooCommerce limits how many it generates in one run, so very large sets may need more than one pass; check the current docs.
  5. Fill in each variation. Price (and sale price), SKU, stock, weight and dimensions if they differ, shipping class, image and an optional short description.
  6. Set default form values. Preselect the most popular option, or leave it blank so shoppers choose deliberately.
  7. Publish and test. Select every option on the live page on a phone, check prices, images and stock messages, and add one variation to the cart.

Price, stock and SKU per variation

  • Price: every variation needs a regular price. If all variations cost the same, set it once with a bulk action
  • SKU: give each variation its own unique SKU, such as TSHIRT-BLU-M. It makes order picking, stock counts and syncing with billing or marketplace software far easier
  • Stock per variation: tick "Manage stock?" on each variation to track sizes and colours separately. If you leave it unticked, the variation follows the parent product's stock settings, which suits made-to-order items
  • "Any" options: a variation can be set to "Any Size", which saves creating combinations, but then you can't track stock or price by size for it
  • Out of stock: decide whether sold-out combinations should show as unavailable or be hidden, and test what your theme actually does

For stock settings, low-stock alerts and syncing with a physical shop, see WooCommerce inventory management.

Bulk editing variations

Editing 40 variations one by one is slow and error-prone. Two built-in tools help:

  • Bulk actions in the Variations tab: set or change regular and sale prices (including increases by an amount or percentage), toggle stock management, set stock status, and set weights and dimensions for all variations of a product at once
  • CSV import and export: WooCommerce's product exporter and importer handle variations as separate rows linked to their parent, which suits large catalogues and seasonal price changes

Bulk changes are hard to undo, so back up first and try a CSV import on a staging copy before running it on the live store. Edits across many products at once, such as raising every price in a category, usually need a dedicated bulk-edit plugin or a short custom script.

Variation images, swatches and size charts

  • Variation images: assign an image to each colour so the main photo changes when the shopper selects it, which reduces confusion and returns. By default each variation gets one image; extra gallery images per variation need a plugin or a theme that supports them
  • Swatches: colour circles and size buttons are easier to use than dropdowns, especially on phones. They come from a swatches plugin or a theme feature, and newer block-based product templates may include button-style options, so check what your setup already offers
  • Size charts: a clear chart beside the size selector, with measurements in the units your customers use
  • Availability: grey out or cross out combinations that are out of stock, so shoppers don't pick an option only to be told it's unavailable

For a worked example where size charts, size buttons and stock by size matter on every product, see websites for footwear stores. Pair good variations with a strong product page; see product page optimisation.

How many variations is too many?

Each variation is stored as its own record in the database, so products with dozens or hundreds of variations make the product editor slower and product pages heavier. There is also a specific front-end limit worth knowing about: the AJAX variation threshold.

  • When a product has fewer variations than the threshold (30 by default at the time of writing), WooCommerce loads all variation data into the page, so it can grey out unavailable combinations as the shopper chooses
  • Above the threshold, WooCommerce instead looks up the chosen variation after all options are selected, so a shopper may only find out a combination is unavailable at the end
  • A developer can raise the threshold with a filter, but every variation then adds to the page weight, so test speed on a phone before and after

Ways to keep variation sets lean:

  • Create only the combinations you actually sell, not every possible one
  • Use product add-ons for options that don't need separate stock, like gift wrapping, engraving or a printed name
  • Split very different versions into separate products, such as a cotton and a silk range

For other store speed fixes, see the WooCommerce speed optimisation guide.

SEO for variable products

  • One URL per product: variations share the product URL, which keeps ranking signals together. Links that preselect an option add a query parameter, and the canonical tag should point back to the main product URL; see canonical tags explained
  • Describe the options in text: mention available sizes, colours and materials in the description, not just in the dropdowns
  • Image alt text: describe each variation image, such as "navy cotton T-shirt, front view"
  • Structured data: WooCommerce's built-in product markup typically shows a price range for variable products. Google also supports markup for product variants; support in SEO plugins varies, so check current docs
  • Shopping feeds: Google Merchant Center treats each variation as its own item grouped under the parent, so each needs accurate price, stock and a GTIN where one exists; see Google Merchant Center for WooCommerce
  • When to split: if a version has strong search demand of its own, a separate product page can rank for it better than a dropdown option

For category pages, titles and product schema, see the WooCommerce SEO guide.

Common mistakes

  • Leaving a variation without a price, so it silently doesn't appear for sale
  • Using custom attributes for size and colour, then finding filters don't work
  • Generating every combination when only a few exist, then selling items you don't have
  • Reusing the same SKU on several variations
  • Forgetting variation images, so the photo doesn't match the colour chosen
  • Running a big CSV import on the live store without a backup

FAQs

What is the difference between an attribute and a variation in WooCommerce?

An attribute is an option type, like Size, with terms such as S, M and L. A variation is one purchasable combination of those terms, like Medium and Blue, with its own price, stock and SKU.

Why is my WooCommerce variation not showing?

The usual causes are a missing price, the variation being disabled, it being out of stock with out-of-stock items hidden, or the attribute not ticked as "Used for variations". Check each in the Variations and Attributes tabs.

How many variations can a WooCommerce product have?

There is no small hard limit, but large numbers slow the editor and product page, and above the AJAX variation threshold the page stops greying out unavailable combinations in advance. Keep sets to what you actually sell.

Can each variation have its own images?

Each variation can have one image by default. Several gallery images per variation need a plugin or a theme that supports it.

Do I need a plugin for colour swatches?

Usually, yes, unless your theme or product template already includes them. Choose a well-maintained option and check it doesn't add heavy scripts to every page.
