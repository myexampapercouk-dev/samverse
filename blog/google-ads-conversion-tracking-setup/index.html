Google Ads Conversion Tracking on WordPress and WooCommerce: Forms, Calls and Purchases

Set up Google Ads conversion tracking on WordPress and WooCommerce: track forms, calls, WhatsApp clicks and purchases with order value, then test each one.

Key takeaways
  • Decide which actions really matter, such as enquiries, calls and purchases, and mark only those as primary conversions so Google Ads optimises for real leads.
  • Track form submissions on the thank-you step, calls and WhatsApp clicks as separate actions, and WooCommerce purchases with order value on the order-received page.
  • Test every conversion with Tag Assistant and a real test enquiry before spending, and check consent settings, duplicate counting and the conversion window.

Google Ads conversion tracking on WordPress and WooCommerce tells Google which clicks turned into enquiries, calls or sales, so you can see what your ad spend actually produces and let bidding optimise for real results. To set it up, decide which actions count, send them to Google Ads either through the Google tag or by importing GA4 key events, and test each one before you spend more.

This guide walks through the choices and setup for forms, phone calls, WhatsApp clicks and WooCommerce purchases, with the common mistakes Indian small businesses run into.

Why conversion tracking matters before you scale ads

Without tracking, Google Ads only knows about clicks. Smart bidding strategies such as Maximise Conversions need conversion data to work properly, and you cannot tell which keywords bring leads and which only bring traffic. Many small businesses run ads for months on clicks alone and then decide "Google Ads doesn't work", when the real problem is that nobody could see what was working. If you are still planning a budget, read how to set a Google Ads budget for a small business first.

How to set up Google Ads conversion tracking on WordPress

There are two main routes, and you should pick one per action to avoid counting twice.

Route 1: Import GA4 key events

If GA4 is already installed and tracking your forms and purchases, link GA4 to Google Ads, mark the events as key events in GA4, then import them into Google Ads as conversions. This is simpler to maintain and keeps one source of truth. The guide to GA4 events explains how events and key events work, and setting up Google Analytics and Search Console covers the basics.

Route 2: Google Ads conversion tag

Create a conversion action in Google Ads and fire its tag through Google Tag Manager or the Google tag on the thank-you step. This tends to report faster and supports features such as enhanced conversions directly. It needs a little more setup.

Many sites use Tag Manager for both, which keeps tracking code out of the theme and makes testing easier.

Tracking form submissions

The most reliable method is a thank-you page: after a successful submission, the form redirects to a page such as /thank-you/, and the conversion fires on that page only. Make sure the thank-you page cannot be reached in other ways, such as from the menu or Google search, by keeping it out of navigation and setting it to noindex.

If your form shows a success message without changing page, you need an event that fires on successful submission. Popular WordPress form plugins expose such events or have integrations; avoid tracking the button click alone, because it also counts failed or empty submissions. Check your form plugin's documentation for the exact event name.

Tracking calls and WhatsApp clicks

For many Indian service businesses, calls and WhatsApp bring more leads than forms. Track them separately so you can judge each:

  • Calls from ads: use call assets with Google forwarding numbers where available, and set a minimum call length so short misdials do not count.
  • Clicks on phone numbers on the site: track clicks on tel: links as a conversion. This shows intent, not a completed call.
  • WhatsApp clicks: track clicks on wa.me or api.whatsapp.com links. Again, this is intent; the chat may never start.

Because click-based conversions overcount, many businesses keep WhatsApp clicks as secondary at first and review actual chats before promoting them to primary. For deeper call measurement, see call tracking for small businesses.

Tracking WooCommerce purchases

Purchases should fire once, on the order-received page, with the order value, currency (INR) and order ID. The order ID lets Google deduplicate if a customer reloads the page. Several WooCommerce integrations send purchase data to GA4 and Google Ads; check that yours includes value and transaction ID.

Two Indian-specific issues to watch:

  • Payment gateway redirects. With Razorpay, PayU or similar, the customer goes to the gateway and back. If they close the tab before returning, the purchase may not be tracked. Server-side or GA4 measurement protocol options can help, but at minimum compare tracked orders with WooCommerce orders weekly.
  • Cash on delivery. COD orders are placed but not yet paid, and some will be refused. Decide whether to count them at full value, and consider adjusting conversions later for returned or cancelled orders.

For ads that also run on Meta, the Meta Pixel and Conversions API guide explains the equivalent setup there.

WooCommerce conversion tracking for Google Ads: getting the details right

For a store, a purchase conversion that simply fires is not enough. To let Google Ads judge which campaigns actually make money, the purchase event needs to carry the right details and fire only once per order:

  • Send the order value and currency: pass the real order total in INR so you can see revenue per campaign, not just a count of sales.
  • Send the order ID as the transaction ID: this lets Google Ads ignore duplicates when a customer refreshes or revisits the thank-you page.
  • Fire on the order received page only: not on checkout, not on clicks of the Place Order button, which also count failed payments.
  • Check gateway redirects: some Indian payment gateways return customers through extra pages. Make sure customers still land on the WooCommerce thank-you page after paying, or the conversion is lost.
  • Pick one source: use either the Google for WooCommerce extension, a tag manager setup or GA4 import for purchases, not all three, or sales get counted twice.

Then compare a week of Google Ads purchase conversions with the orders in WooCommerce. They will never match exactly, but a large gap means something in the setup needs fixing.

Measuring lead quality, not just lead count

A form submission is not a customer. For service businesses, the next step is to check which conversions turned into real jobs. Keep a simple sheet or CRM that records the source of each lead, and note whether it was genuine, a wrong number, spam or a sale. Over a few weeks you will see which campaigns and keywords bring useful enquiries.

When you have enough volume, Google Ads can also accept offline conversion imports, where you upload leads that became sales using the click ID captured on the form. This lets bidding favour searches that lead to real business rather than any enquiry. It needs a hidden field on the form to store the click ID and a routine for uploading results, so it suits businesses with a steady flow of leads. The guide to lead scoring for small businesses explains how to grade enquiries consistently.

Enhanced conversions and consent

Enhanced conversions send hashed customer data, such as email or phone from the form, to improve matching when cookies are limited. It can improve measurement, but it involves personal data, so check your privacy policy explains it and that you have the right consent. India's data protection law and Google's own policies both apply; check the current rules. If you have visitors from regions that require consent mode, set it up properly with your consent banner.

Test before you spend

  1. Use Google Tag Assistant to load your site and confirm the tag and conversion fire on the right step.
  2. Submit a real test enquiry and make a test purchase (a low-value product or a coupon), then check that each shows in Google Ads within a day.
  3. Check the conversion status in Google Ads changes from "Unverified" to recording conversions.
  4. Compare a week of conversions with actual leads in your inbox and orders in WooCommerce.

Before launching ads, also check your landing page. The guide on getting your website ready for Google Ads covers what to fix first, such as slow loading, unclear offers and missing contact buttons.

Common mistakes to avoid

  • Counting the same conversion twice, once from GA4 import and once from the Ads tag.
  • Firing the conversion on button clicks instead of successful submissions.
  • Marking micro actions such as page views as primary conversions.
  • Thank-you pages that are linked from the menu or indexed, so ordinary visits count as leads.
  • Never comparing tracked conversions with real enquiries and orders.
  • Changing the site or form plugin and forgetting that tracking depended on it.

FAQs

How do I set up Google Ads conversion tracking on WordPress?

Decide your conversions, then either import GA4 key events into Google Ads or fire a Google Ads conversion tag through Tag Manager on the thank-you step. Test with Tag Assistant and a real test enquiry before relying on the data.

Should I use GA4 import or the Google Ads tag?

Either works. GA4 import is simpler to manage from one place; the Ads tag reports faster and supports some features directly. Use one route per action so nothing is counted twice.

Can I track WhatsApp clicks as conversions?

Yes, by tracking clicks on WhatsApp links. Treat them as intent rather than confirmed leads, and many businesses keep them as secondary until they check the quality of chats.

Why are my Google Ads conversions lower than my real orders?

Common causes are customers not returning from the payment gateway, ad blockers, consent settings, or tags missing on some pages. Compare reports with real orders and fix gaps step by step.

Do COD orders count as conversions?

They are tracked when the order is placed. Decide whether to count them at full value, and adjust later for cancelled or refused orders if your setup supports it.

How do I set up WooCommerce conversion tracking for Google Ads?

Use one method, such as the Google for WooCommerce extension or a Google tag through Tag Manager, to fire a purchase conversion on the order received page with the order value, currency and order ID. Then place a test order and confirm it appears in Google Ads.
