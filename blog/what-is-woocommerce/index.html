What Is WooCommerce? How It Works, What You Need and Who It Suits

WooCommerce is a free plugin that turns a WordPress site into an online store. How it works, what you need, costs, pros, cons and how to start.

Key takeaways
  • WooCommerce is a free, open-source plugin that turns a self-hosted WordPress site into an online store with products, cart, checkout, payments, shipping and orders.
  • You need a domain, good WordPress hosting, an SSL certificate, a WooCommerce-ready theme, a payment gateway and working email delivery.
  • The core plugin is free; extras such as subscriptions, GST invoices and filters come from extensions, which are also plugins.

WooCommerce is a free, open-source plugin that turns a WordPress website into an online store, adding products, a cart, checkout, payments, shipping, tax and order management to the site you already control.

It is not a separate website builder or a hosted service. You install it on a self-hosted WordPress site, the same way you install any other plugin, and your store lives on your own hosting.

How WooCommerce works

WordPress handles the website: pages, blog, menus, users and the theme. WooCommerce plugs into it and adds the shop layer:

  • Products: simple, variable (sizes, colours), grouped and external products, each with price, stock, SKU, images and categories.
  • Cart and checkout: customers add items, enter address details and pay. Newer installs use the Cart and Checkout blocks.
  • Payments: through payment gateway plugins, for example Razorpay, PayU, Stripe, PayPal, or offline methods such as cash on delivery and bank transfer.
  • Shipping and tax: shipping zones, flat rates, free shipping rules and tax settings under WooCommerce > Settings.
  • Orders and customers: each order gets a status (Pending payment, Processing, Completed, Refunded) under WooCommerce > Orders, with emails sent to you and the buyer.

Everything else (subscriptions, bookings, GST invoices, product filters, abandoned cart emails) comes from extensions, which are also plugins.

What you need to run a WooCommerce store

  1. A domain name, such as yourbrand.in or yourbrand.com.
  2. Web hosting that runs WordPress well. A store needs more server resources than a brochure site because cart and checkout pages cannot be fully cached.
  3. WordPress, the self-hosted version from wordpress.org (not a WordPress.com plan that limits plugins).
  4. An SSL certificate so the site loads on https. See how to install SSL on WordPress.
  5. A theme that supports WooCommerce, for example Storefront, Astra, Kadence or a block theme.
  6. A payment gateway account. For Indian stores, see how to add Razorpay to WooCommerce.
  7. Working email delivery so order emails reach customers. See how to set up SMTP on WordPress.

WooCommerce pricing in India

The core WooCommerce plugin is free in India as everywhere else. Your real WooCommerce pricing comes from hosting, a domain, an optional paid theme, any paid extensions and your payment gateway's per-transaction fees, and each of these varies by provider and store size:

Cost itemFree or paid?What changes the amount
WooCommerce pluginFreeNothing; core is free to use
DomainPaid, yearlyExtension (.in, .com) and registrar
HostingPaid, monthly or yearlyTraffic, number of products, shared vs managed or cloud hosting
ThemeFree or paidFree themes work; premium themes add design options and support
ExtensionsMany free, many paid (often yearly licences)Features you need: subscriptions, bookings, filters, invoices
Payment gateway feesPer transactionYour gateway's pricing and payment method
Development and maintenanceYour time or a developer'sCustom design, integrations, updates, backups and security

WooCommerce itself does not take a platform fee on each sale, but your payment gateway still charges its own fee.

WooCommerce pros

  • Free core and no platform fee on sales.
  • Full ownership: your files, database and customer data sit on your hosting and can be moved.
  • Flexible: thousands of plugins and full code access for custom features.
  • Content and SEO: WordPress is strong for blogs, landing pages and SEO plugins alongside the shop.
  • Local payment and shipping options through Indian gateway and courier plugins.

WooCommerce cons

  • You manage it: updates, backups, security and hosting are your responsibility (or your developer's).
  • Plugin overload: too many extensions slow the store and cause conflicts.
  • Performance depends on hosting: cheap shared hosting struggles with busy checkouts.
  • Paid extensions add up over time with yearly renewals.

WooCommerce vs Shopify: who each suits

WooCommerce suits you if you already have a WordPress site, want full control and custom features, publish a lot of content, or don't want a monthly platform subscription. Shopify suits you if you want a hosted platform where security, hosting and updates are handled for you and you are happy to work within its apps and plans.

For a detailed comparison for Indian sellers, read WooCommerce vs Shopify in India.

How to start a WooCommerce store

  1. Buy a domain and hosting, then install WordPress (most hosts offer one-click install).
  2. Install SSL and confirm the site loads on https.
  3. Go to Plugins > Add New Plugin, search for WooCommerce, click Install Now and then Activate.
  4. Complete the setup wizard: store address, industry, product types and currency (Indian Rupee for India).
  5. Set payments in WooCommerce > Settings > Payments, shipping in WooCommerce > Settings > Shipping and tax in WooCommerce > Settings > Tax.
  6. Add products under Products > Add New Product.
  7. Place a test order end to end before launch. The WooCommerce launch checklist covers what to check.

Two edge cases people miss: the Shop, Cart, Checkout and My account pages are created by the wizard, so if you delete one, reassign it in WooCommerce > Settings > Advanced or checkout breaks. And caching plugins must exclude cart, checkout and my-account pages, or customers can see stale carts.

FAQs

Is WooCommerce free?

Yes, the core WooCommerce plugin is free and open source. You still pay for a domain, hosting, any paid themes or extensions, and payment gateway transaction fees.

Is WooCommerce the same as WordPress?

No. WordPress is the content management system; WooCommerce is a plugin that adds e-commerce to it. You need WordPress to use WooCommerce.

Can I use WooCommerce on WordPress.com?

Only on WordPress.com plans that allow plugins. Most stores use self-hosted WordPress from wordpress.org on their own hosting.

Is WooCommerce good for beginners?

It is manageable if you are comfortable with WordPress, but you handle hosting, updates and backups yourself. Beginners who want everything managed often find Shopify simpler.

Does WooCommerce work in India?

Yes. It supports Indian Rupee, GST tax settings, and Indian payment gateways such as Razorpay, PayU and Cashfree, plus cash on delivery.
