WordPress Child Themes Explained: What They Are, When You Need One and How to Create One (With Code)

WordPress child theme explained: when you need one, how to create it with style.css and functions.php enqueue code, template overrides and common fixes.

Key takeaways
  • A child theme inherits everything from its parent theme and holds only your changes, so the parent can be updated without wiping out custom code or template edits.
  • It needs just a folder, a style.css file whose Template line names the parent folder, and a functions.php that loads the stylesheets; WP-CLI or the theme vendor can generate one for you.
  • Use a child theme for theme templates and theme-specific code, not for small CSS tweaks or site-wide features, and test the switch on staging because Customizer settings may not carry over.

A WordPress child theme is a small theme that inherits its design and features from a parent theme and contains only your changes. Because your custom CSS, PHP and template edits live in the child theme, the parent can be updated safely without wiping them out. To create one, add a folder in wp-content/themes with a style.css file whose Template line names the parent theme's folder and a functions.php file that loads the stylesheets, then activate it. You need one if you edit theme templates or add theme-specific code, not for a few lines of CSS.

If you'd rather have it set up properly, I can create a child theme, move any direct edits out of the parent and test the switch on staging as part of WordPress website development work.

Child themes matter most when it's time to update. If you're about to update a premium theme that someone has edited, read how to update a premium theme safely as well.

How a child theme works

When a child theme is active, WordPress uses the child's files where they exist and falls back to the parent for everything else.

File in the child themeWhat happens
style.cssRequired. Its header names the child theme and, through the Template line, its parent
functions.phpLoaded in addition to the parent's functions.php, just before it. It doesn't replace the parent's file
Template files such as header.php or single.phpReplace the parent's file at the same path
woocommerce/ folderOverrides WooCommerce templates for this theme
theme.json (block themes)Merged with the parent's settings, with the child's values taking priority
screenshot.pngOptional thumbnail shown in Appearance > Themes

When you need a child theme, and when you don't

The change you wantBest place for it
Edit a theme template, such as the header or single post layoutChild theme
PHP that hooks into your theme's own functionsChild theme's functions.php
Override WooCommerce templatesChild theme
A large amount of custom CSS that belongs with the designChild theme's style.css
A few lines of CSSAppearance > Customize > Additional CSS, or your page builder's custom CSS
Features you'd want to keep if you changed theme, such as custom post types, tracking or integrationsA small custom plugin
A site built entirely in Elementor with no code changesNone needed yet

The rule of thumb: design and presentation belong in the child theme; functionality belongs in a plugin, so it survives a change of theme. See plugin or custom code for more on that choice.

How to create a child theme step by step

This example creates a child theme for Astra. Swap in your own parent theme's details.

Step 1: Create the folder

Find the parent theme's folder name in wp-content/themes, for example astra, and create a new folder next to it, such as astra-child. The Template line in the next step must match the parent's folder name exactly, including capital letters.

Step 2: Add style.css

Create a style.css file in the new folder with this header. Theme Name and Template are required; the version number is used in the next step:

/*
Theme Name:  Astra Child
Template:    astra
Version:     1.0.0
Description: Child theme for Astra
Text Domain: astra-child
*/

Step 3: Add functions.php and enqueue the stylesheets

Create a functions.php file that loads the child theme's stylesheet after the parent's. Many modern themes, Astra included, already load their own stylesheet, so you only need to enqueue the child's, with the parent's stylesheet handle as a dependency. Astra's handle is astra-theme-css at the time of writing; check your theme's documentation for its own.

<?php
add_action( 'wp_enqueue_scripts', 'astra_child_enqueue_styles', 15 );
function astra_child_enqueue_styles() {
    wp_enqueue_style(
        'astra-child-style',
        get_stylesheet_uri(),
        array( 'astra-theme-css' ),
        wp_get_theme()->get( 'Version' )
    );
}

Some older themes load style.css with a function that, once a child theme is active, picks up the child's file instead of the parent's. In that case, load the parent's stylesheet explicitly first, as the WordPress theme handbook shows:

<?php
add_action( 'wp_enqueue_scripts', 'my_child_enqueue_styles' );
function my_child_enqueue_styles() {
    $theme = wp_get_theme();
    wp_enqueue_style( 'parent-style', get_template_directory_uri() . '/style.css', array(), $theme->parent()->get( 'Version' ) );
    wp_enqueue_style( 'child-style', get_stylesheet_uri(), array( 'parent-style' ), $theme->get( 'Version' ) );
}

Step 4: Upload and activate

Zip the folder and upload it under Appearance > Themes > Add New Theme > Upload Theme, or copy the folder over SFTP. Then activate the child theme and check the site.

The quicker way: WP-CLI or a generator

With WP-CLI, one command creates the folder, style.css and functions.php, and can activate it:

wp scaffold child-theme astra-child --parent_theme=astra --theme_name="Astra Child" --activate

Many theme vendors also offer a ready-made child theme or a generator, and for block themes the Create Block Theme plugin can make a child theme from the Site Editor.

Before you switch a live site to a child theme

WordPress stores many Customizer settings per theme, so a newly activated child theme can start without your parent theme's header, colours, menu locations or widgets. Some themes keep their settings in a way that carries over; others don't. Note or export your settings first, using the theme's own export option or a Customizer export plugin, and make the switch on a staging copy before doing it live; see staging sites explained.

Moving existing edits out of the parent theme

If someone has already edited the parent theme directly, move those changes into the child before the next update overwrites them:

  1. Find what changed. Download a fresh copy of the same parent version from the vendor and compare the folders, for example with diff -rq over SSH or a desktop comparison tool.
  2. Copy each edited template into the child theme at the same path.
  3. Move added CSS into the child's style.css, and added PHP functions into the child's functions.php. Because the child's functions.php loads first, a parent function wrapped in a function_exists check can be replaced by defining a function with the same name in the child; any other duplicate name causes a fatal error.
  4. Activate the child on staging, restore Customizer settings and menus, and test key pages, forms and checkout.
  5. Replace the parent with a clean copy of the latest version, then test again before going live.

Overriding template files

To change a template, copy it from the parent theme into the same path in the child theme and edit the copy. For WooCommerce, copy templates from wp-content/plugins/woocommerce/templates/ into a woocommerce folder in the child theme. WooCommerce > Status later warns you when a copied template is out of date.

Copied templates don't receive the parent's fixes, so keep them to a minimum. Where your theme or WordPress offers a hook or filter, use that in functions.php instead. For example, this changes the length of post excerpts without touching a single template:

add_filter( 'excerpt_length', function () {
    return 30;
} );

Child themes for block themes

Block themes can have child themes too. A child's theme.json changes colours, fonts and spacing, and HTML files in its templates and parts folders override the parent's. Changes you make in the Site Editor are saved in the database rather than in theme files, so they survive parent updates anyway; a child theme is mainly useful when you want those changes stored as files you control. See block themes explained.

FAQs

What is a child theme in WordPress?

A theme that inherits everything from another theme, its parent, and contains only your changes. It lets you customise the theme's code and templates while still updating the parent safely.

Do I need a child theme with Elementor?

Not if you only build pages and templates in Elementor, because those are stored in the database and survive theme updates. Add a child theme when you start adding custom PHP or template changes; see choosing a theme for Elementor.

Will a child theme slow down my site?

Not noticeably. It usually adds one small stylesheet. A child theme full of heavy custom code is a different matter, but that's the code, not the child theme.

What happens to my child theme when the parent updates?

The child theme itself is untouched. After a major parent update, check any templates you copied into the child, because the parent's versions may have changed.

Can I create a child theme without a plugin?

Yes. You only need a folder with style.css and functions.php, as shown above. WP-CLI and theme vendors' generators are simply quicker.

Can a child theme have its own child theme?

No. WordPress supports one level only: a parent and a child. If you need more separation, move functionality into a custom plugin or consider a custom theme.
