SEO for WordPress Category and Tag Pages: Index, Noindex or Improve?

When to index or noindex WordPress category and tag pages, how to write category intros that can rank, clean up thin tag archives and handle pagination.

Key takeaways
  • Index category archives that collect several posts and give them a unique intro; noindex thin tag, author and date archives.
  • Clean up tag sprawl by merging duplicates, removing one-off tags and redirecting any archive that still gets traffic.
  • Give each paginated page its own canonical, show the intro only on page one and use plain, crawlable pagination links.

Every time you add a category or tag to a WordPress post, WordPress quietly creates a page that lists all posts with that label. On a small business blog, these archive pages can either become useful entry points from Google or pile up into dozens of thin, near-empty pages. Here's how to decide which ones deserve to be indexed, and how to make the good ones worth ranking.

What category and tag archives are

WordPress organises posts with two built-in taxonomies:

  • Categories are broad and hierarchical (they can have sub-categories). Every post has at least one; if you don't choose, it goes into the default "Uncategorized".
  • Tags are optional, flat labels for more specific details.

Each category and tag gets its own archive URL, typically /category/gst/ or /tag/elementor/, showing a list of matching posts. WooCommerce does the same for product categories and product tags. Unless you tell them otherwise, search engines can find and index all of these pages.

Use categories for structure, tags sparingly

Most archive problems start with how categories and tags are used, not with settings.

  • Keep categories few and broad, matching the main topics your customers care about. For a CA firm that might be GST, income tax, company registration and compliance.
  • Rename "Uncategorized" to something meaningful, or make sure no post stays in it.
  • Put each post in one main category where possible. Several categories per post make archives overlap.
  • Use tags only if you'll apply them consistently, and only for labels that will collect several posts. Many small business blogs are better off with no tags at all.

Index or noindex? A simple rule

Ask of each archive: would a searcher landing on this page find it useful, and does it offer something no single post does? If yes, let it be indexed and improve it. If not, keep it out of Google's index with a noindex tag. Visitors can still browse it; it just won't appear in search results.

Archive typeUsual recommendation
Main blog categories with several postsIndex, and add a unique intro
WooCommerce product categoriesIndex; these are often a store's best-ranking pages
Tag archivesUsually noindex, unless a tag is a curated, well-populated topic
Categories with only one or two postsNoindex or merge until they grow
Author archives on a one-author siteNoindex or disable; they duplicate the main blog
Date archivesNoindex or disable

SEO plugins such as Yoast SEO and Rank Math let you set this for each taxonomy (and usually for individual categories or tags), and generally leave noindexed archives out of the XML sitemap. Don't block archives in robots.txt instead: Google can't see a noindex tag on a page it isn't allowed to crawl. For the wider picture, see duplicate content explained.

Write category intros that earn a ranking

A bare list of post titles and excerpts rarely deserves to rank. A short introduction at the top turns a category into a proper landing page. WordPress has a description field for each category (under Posts, then Categories); whether it appears on the page depends on your theme, though many themes show it above the post list.

A good category intro:

  • Runs to roughly 80–200 words, written for people rather than stuffed with keywords
  • Explains what the topic covers and who it's for
  • Points to the two or three most useful posts to start with
  • Links to the related service page, such as GST registration or bookkeeping
  • Has its own SEO title and meta description, set in your SEO plugin

The same idea applies to WooCommerce product categories: a brief guide to the range and how to choose. See WooCommerce SEO for store-specific advice.

Avoid thin tag archives

Tag sprawl is common on blogs that have been running for a few years: dozens of tags used once, near-duplicates like "SEO tips", "seo-tip" and "SEO Tips 2024", and tags that repeat category names. Each one is a page with almost nothing on it. To clean up:

  1. Open the Tags screen in WordPress, which shows how many posts use each tag.
  2. Merge duplicates and remove tags used on only one or two posts.
  3. Before deleting a tag or category, check Search Console for traffic or links to its archive. If it has some, 301-redirect it to the closest category.
  4. Set the remaining tag archives to noindex unless you've deliberately built them up.
  5. Agree simple rules with whoever writes posts, so the mess doesn't return.

Handle pagination properly

Once a category has more posts than fit on one page, WordPress splits it into /page/2/, /page/3/ and so on. A few points keep this healthy:

  • Let each paginated page be its own canonical. Pointing page 2 onwards to page 1 as the canonical asks Google to ignore the posts listed there. See canonical tags explained.
  • Show the category intro only on page 1, so later pages don't repeat the same text. Many themes already do this; check yours.
  • Use real links for pagination. "Load more" buttons and infinite scroll that work only through JavaScript can stop Google reaching older posts. Plain numbered links are the safest option.
  • Don't rely on pagination alone. Link important older posts from newer ones and from the category intro, so they aren't buried five pages deep.

Google no longer uses the old rel="next" and rel="prev" tags as an indexing signal, so adding them isn't a fix on its own, although they do no harm.

Check your archives in Search Console

After changing settings, keep an eye on the Pages report in Google Search Console. Noindexed tag archives will appear under "Excluded by 'noindex' tag", which is expected. Category pages you want indexed should show as indexed; if they sit under "Crawled - currently not indexed", Google doesn't yet see enough value in them, which usually means a thin intro or too few posts.
