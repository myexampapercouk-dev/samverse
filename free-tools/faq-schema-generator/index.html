FAQ schema generator (FAQPage JSON-LD)

Type your questions and answers and the FAQPage structured data updates as you go. Copy it, paste it into the page that shows the same FAQ, and test it.

Questions and answers

    FAQPage JSON-LD

    How to use it

    1. Type each question exactly as it appears on your page, then its answer in plain text.
    2. Add at least two questions. Remove empty rows or they are left out of the code.
    3. Copy the JSON-LD and paste it into the page that shows those questions.
    4. Test the page in Google's Rich Results Test before and after publishing.

    For which questions to write and how to lay out the page, see how to write an FAQ page that helps SEO. To check your markup, follow how to test structured data and rich results.

    FAQ

    FAQ schema questions

    Does FAQ schema still show rich results in Google?

    Google now shows FAQ rich results mainly for well-known government and health websites, so most sites will not see the expandable answers. The markup is still valid structured data that helps search engines and AI answer tools understand your questions and answers.

    Where do I paste the JSON-LD?

    Inside the page that shows the same questions and answers, either in the head or the body, wrapped in the script tag the tool outputs. In WordPress you can use a code snippet plugin, a custom HTML block or your SEO plugin's schema settings.

    Can I use FAQ schema for questions that are not on the page?

    No. Google's guidelines say the questions and answers in the markup must be visible to users on the same page. Hidden or different content can be treated as spammy structured data.

    Can answers contain links or formatting?

    Google allows a few basic HTML tags in answers, such as links, lists and bold text. Plain text is the safest choice and is what this tool expects; any HTML you type is escaped so it shows up literally.

    How do I test the output?

    Paste the full code into Google's Rich Results Test or the Schema Markup Validator. Both are free and show any errors or warnings.
