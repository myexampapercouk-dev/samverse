QR code generator for URL, WiFi and vCard

Create a static QR code for a link, plain text, your WiFi network or a contact card. It does not expire and does not redirect through anyone else, because the data is in the code itself.

Runs 100% in your browser. Nothing you add is uploaded to any server. The small open-source QR library loads from a CDN; your data is encoded on your device.

Your QR code

How to use it

  1. Pick the type: URL, text, WiFi or contact card.
  2. Fill in the details. The code updates as you type.
  3. Set the size and colours. Keep strong contrast, dark on light, so phones can read it.
  4. Scan it with your phone to test, then download PNG for screens or SVG for print.

FAQ

QR code questions

Do these QR codes expire?

No. They are static codes with the data inside them, so they keep working as long as the link or details inside stay valid.

PNG or SVG?

PNG for websites, slides and social posts. SVG for print, because it scales to any size without going blurry.

What does error correction do?

Higher levels let the code still scan when part of it is damaged or covered, but make it denser. Medium suits most uses.

Can I track scans?

Not with a static code. Put a UTM-tagged URL in the code and you can see the visits in Google Analytics.
