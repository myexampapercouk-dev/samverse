JSON and JSON-LD formatter and validator

Paste JSON or a JSON-LD schema block to format it, minify it or find the exact line and column of a syntax error. Script tags around JSON-LD are stripped automatically.

Runs 100% in your browser. Nothing you add is uploaded to any server.

    Result

    How to use it

    1. Paste your JSON or JSON-LD, with or without the script tags.
    2. Press Format to pretty-print it or Minify to compress it.
    3. If there is an error, fix it at the line and column shown.
    4. Copy the result. For schema, also test it in the Rich Results Test.

    FAQ

    JSON formatter questions

    Does valid JSON mean my schema is valid?

    Not always. Valid JSON is the first step. Google also checks the schema types and required properties, so test the page in the Rich Results Test too.

    What are the most common JSON errors?

    Trailing commas, single quotes instead of double quotes, curly quotes pasted from a word processor, and missing commas between items.

    Is my data sent anywhere?

    No. Parsing and formatting happen in your browser.
